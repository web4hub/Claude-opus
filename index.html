What is here?

The upstream bucket describes four primary dataset splits: full_train.jsonl, instruct_train.jsonl, roleplay_train.jsonl, and code_train.jsonl. The repository does not vendor those large dataset artifacts; it documents the source and provides tooling to retrieve the separate model archive.

Model download

Use the included installer to download the model archive from the configured Kaggle endpoint. The script uses strict shell mode, retries, and an optional checksum.

chmod +x install.sh
./install.sh

Dataset provenance

The dataset documentation states that it was generated with Claude Opus 4.6/4.7 and was not manually reviewed. Treat it as synthetic research material, not verified ground truth.

Responsible use

Do not present synthetic reasoning traces as access to a model's private chain-of-thought. Treat them as generated training artifacts and evaluate licensing, provenance, privacy, bias, and downstream safety before training or redistribution.
